# Condiciones de Servicio de Froggy 🐸

**Última actualización:** 12/08/2026

Gracias por usar Froggy, un bot de mascotas virtuales para Discord. Al usar Froggy en tu servidor, aceptas las siguientes condiciones.

## 1. Descripción del servicio

Froggy es un bot de entretenimiento que permite a los usuarios adoptar y cuidar una mascota virtual dentro de Discord (alimentarla, subir su nivel, ver un ranking, etc.). El servicio se ofrece de forma gratuita y "tal cual", sin garantías de disponibilidad continua.

## 2. Datos que recopilamos

Para funcionar, Froggy guarda de forma automática:

- Tu ID de usuario de Discord
- El nombre que le pongas a tu mascota
- Las estadísticas de tu mascota (vida, energía, hambre, felicidad, nivel)

No recopilamos contraseñas, datos de pago, ni ningún dato personal más allá de lo indicado. Esta información se usa únicamente para el funcionamiento del bot (guardar tu progreso y mostrar el ranking).

## 3. Uso aceptable

Al usar Froggy, aceptas no:

- Intentar explotar fallos del bot para obtener ventajas injustas
- Usar el bot para acosar, insultar o molestar a otros usuarios
- Intentar sobrecargar o dañar el funcionamiento del bot deliberadamente

El uso indebido puede resultar en la restricción del acceso al bot en el servidor correspondiente.

## 4. Disponibilidad del servicio

Froggy se ofrece de forma gratuita, sin garantía de funcionamiento ininterrumpido. El servicio puede sufrir caídas, mantenimiento o cambios sin previo aviso. No nos hacemos responsables de la pérdida de datos de tu mascota virtual derivada de fallos técnicos, aunque intentamos evitarlo.

## 5. Eliminación de datos

Puedes solicitar la eliminación de los datos de tu mascota contactando con el administrador del bot. Si el bot es retirado de tu servidor, los datos asociados a ese servidor podrán eliminarse.

## 6. Cambios en el servicio

Nos reservamos el derecho de modificar, actualizar o discontinuar Froggy (o cualquiera de sus funciones) en cualquier momento, sin previo aviso.

## 7. Cambios en estas condiciones

Estas condiciones pueden actualizarse en el futuro. El uso continuado del bot después de un cambio implica la aceptación de las nuevas condiciones.

## 8. Contacto

Para dudas, sugerencias o solicitudes relacionadas con estas condiciones, puedes contactar con el administrador del bot a través del servidor oficial de Froggy.
